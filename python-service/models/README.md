# Pesos OpenCV Zoo locais

Este diretorio deve conter os modelos da arquitetura B e permanece fora do Git. Baixe os dois
arquivos pelos links oficiais, apos revisar as licencas e a adequacao ao seu uso:

- `face_detection_yunet_2023mar.onnx`:
  <https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet>
- `face_recognition_sface_2021dec.onnx`:
  <https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface>

O OpenCV Zoo declara MIT para o diretorio YuNet e Apache-2.0 para o diretorio SFace. Nao coloque
imagens, embeddings, datasets ou backups neste diretorio.
